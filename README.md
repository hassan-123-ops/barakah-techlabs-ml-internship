
# Barakah TechLabs — Machine Learning Internship

This repository contains two Machine Learning internship tasks completed using Python and Scikit-learn.

## Task 1: Data Preprocessing & Pipeline Construction

- Missing value imputation
- Numerical feature scaling using StandardScaler
- Categorical encoding using OneHotEncoder
- Pipeline and ColumnTransformer
- Custom transformer demonstration

Source: `task1-data-preprocessing/task1_preprocessing.py`

## Task 2: Model Training & Hyperparameter Tuning

- Random Forest classification
- Training and testing data split
- Hyperparameter tuning using GridSearchCV
- Evaluation using accuracy, precision, recall, confusion matrix, and ROC-AUC

Source: `task2-model-tuning/task2_model_tuning.py`

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn

## Installation

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run Task 1:

```bash
python task1-data-preprocessing/task1_preprocessing.py
```

Run Task 2:

```bash
python task2-model-tuning/task2_model_tuning.py
```

## Dataset Note

The scripts currently use small demonstration datasets for educational purposes. Results do not establish real-world predictive performance.
